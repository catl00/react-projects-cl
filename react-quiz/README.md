# 🧠 React Quiz

An interactive web-based quiz application that presents users with targeted questions and provides immediate, real-time feedback. Product following along a Udemy course understanding the basics of React.js

---

## ✨ Features

* **Instant Feedback:** Validates user selections instantly and displays visual feedback for correct and incorrect answers.
* **Score & Progress Tracking:** Dynamically tracks current question index and computes total score upon completion.
* **Interactive UI:** Smooth state transitions between questions with clean result summaries.

---

## 🛠️ Tech Stack & Key Concepts

* **React.js:** Functional state management using `useState` to track active question index, score, and selected options.
* **CSS3:** Dynamic conditional class styling for selected, correct, and incorrect answers.
* **JavaScript (ES6+):** Immutable array methods for managing question data and validating results.

---

## 💡 Technical Insights

* **Conditional Rendering:** Utilized clean ternary patterns and conditional rendering rules to seamlessly swap between active quiz questions and final score screens.
