# 🌐 About Me Website

This application is still in the works. 

A personal portfolio application built with React — serving as a modular, component-based showcase for my projects, front-end development journey, and technical skills.

---

## ✨ Features

* **Modular Architecture:** Built with clean, reusable components for project cards, skill badges, and section layouts.
* **Responsive Design:** Custom layout rules ensuring an optimal experience across mobile, tablet, and desktop viewports.
* **Interactive Showcase:** Dynamic presentation of personal projects, code repositories, and experience.

---

## 🛠️ Tech Stack & Key Concepts

* **React.js:** Functional components, state hooks, and scalable folder organization.
* **CSS3:** Flexbox, CSS Grid, and custom variables for consistent design tokens.
* **HTML5:** Semantic markup prioritized for screen readers and search indexing.

---

## 💡 Technical Insights

* **Component Scalability:** Structured design components (cards, tags, buttons) to allow easy updates whenever new projects or skills are added.
