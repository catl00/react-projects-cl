# 💻 Personal Developer Portfolio

A modern React web application built with Vite — designed to showcase my web engineering projects, interactive UI components, and professional journey bridging Front-End Engineering and UX/UI Design.

---

## ✨ Features

* **Interactive Project Gallery:** Modular project displays featuring custom browser mockups, responsive grid layouts, and direct application preview links.
* **UX/UI Driven Engineering:** Designed in Figma and engineered directly into production-ready React components with custom CSS design tokens.
* **Full-Stack & Data Context:** Seamless front-end state management leveraging back-end fundamentals in Java, Python, and SQL.
* **Reusable UI Components:** Component-driven architecture including custom navigation bars, action rows, and responsive card overlays.
* **Fast Performance & Deployment:** Powered by Vite for instant Hot Module Replacement (HMR) and deployed directly via GitHub Pages (`gh-pages`).

---

## 🛠️ Tech Stack & Key Libraries

* **Frontend Framework:** React 18 (Functional Components, State Hooks, Effects, React Router)
* **Build Tool & Bundler:** Vite
* **Styling & Design System:** Custom CSS (CSS Variables, Flexbox, Responsive Grid)
* **Design & Prototyping:** Figma
* **Deployment & CI/CD:** GitHub Pages (`gh-pages`), Git
* **Methodologies & Workflow:** Agile/Scrum, Azure DevOps, JIRA

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have **Node.js** (v18+ recommended) and **npm** installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/catl00/react-projects-cl.git](https://github.com/catl00/react-projects-cl.git)

2. **Navigate into the project directory:**
   ```bash
   cd react-projects-cl/my-portfolio
3. Install dependencies:**
   ```Bash
   npm install
5. Start the development server:***
   ```Bash
   npm run dev
7. Open the local URL displayed in your terminal (usually http://localhost:5173) to view the portfolio!
